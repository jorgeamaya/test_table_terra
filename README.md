# ProtBindScreen WDL Workflows

This repository contains the Workflow Description Language (WDL) implementations used by ProtBindScreen for cloud-based execution.

Current workflows include:

- SCREEN_SUBMISSION_MODE – preparation and submission of ProtBindScreen prediction jobs.
- SCREEN_ANALYSIS_MODE – analysis and prioritization of ProtBindScreen screening results.
- Additional workflows may be added as the platform evolves.

These workflows are designed for execution on workflow engines that support WDL, including Terra/Cromwell.

# Status

This repository is under active restructuring.

The current `main` branch is not considered functional for end-to-end Terra execution at this time.

Active development and repair work are continuing on the `development` branch.

Documentation, examples, Docker images, input templates, and workflow specifications will be expanded over time.

For information about the ProtBindScreen platform, methodology, and software package, please refer to the associated ProtBindScreen repositories and publication.
